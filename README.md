# BlockBek — privacy policy

Public page for the privacy policy of the **BlockBek** Android game
(`uz.berdiklichev.blockbek`), required by Google Play.

- Policy: https://oberdiklichev.github.io/blockbek-privacy/privacy-policy.html
- Available in English, O'zbek and Русский.

The game itself collects no data, has no ads and does not request the
`INTERNET` permission.
